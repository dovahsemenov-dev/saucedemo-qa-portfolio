Учебный проект по тестированию веб-приложения Swag Labs

Данный проект разработан для демонстрации практических навыков в сфере (QA). В качестве объекта тестирования использовался тренировочный стенд интернет-магазина Sauce Demo. Выполнен полный цикл проверок: от анализа требований и составления тестовой документации до тестирования API и составления SQL-запросов.

Тестовое окружение:
Операционная система: Windows 10 PRO
Браузер: Google Chrome(150.0.7871.127 64 бит)
Инструменты: Postman, онлайн-тренажеры SQL.
