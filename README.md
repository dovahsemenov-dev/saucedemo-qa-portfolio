# saucedemo-qa-portfolio
# Мой учебный проект по тестированию (QA) интернет-магазина Swag Labs

Всем привет! Это мой практический проект, который я сделал с нуля для портфолио. Я взял за основу тренировочный сайт Sauce Demo (интернет-магазин) и прогнал его через полный цикл проверок: от написания чек-листов до тестирования API и запросов к базе данных.

## Что внутри проекта:
*   Тест-план (что и как проверял)
*   Чек-листы и около 70 тест-кейсов на разные модули (логин, корзина, сортировка товаров, покупка)
*   Примеры оформленных баг-репортов
*   Коллекция запросов в Postman для проверки API
*   SQL-запросы, которые пригодятся для работы с БД

## На чем тестировал (Окружение):
*   Компьютер на Windows
*   Браузер: Google Chrome
*   Инструменты: Postman для API, а SQL-запросы писал и проверял в онлайн-тренажере.
