Баг-репорт BUG-08. Некорректный код 405 при операциях с несуществующим бронированием

Компонент: REST API Restful Booker, изменение и удаление (PUT /booking/{id}, DELETE /booking/{id})
Сервис: https://restful-booker.herokuapp.com
Серьезность: Средняя (Minor)
Приоритет: Средний (Medium)

Описание:
Операции PUT и DELETE над несуществующим бронированием возвращают 405 Method Not Allowed,
хотя маршрут и метод валидны по документации. Повторный DELETE уже удалённого
бронирования также даёт 405. GET для тех же идентификаторов корректно возвращает 404.
405 сообщает клиенту, что метод в принципе нельзя использовать по этому адресу,
что неверно: использовать его можно, ресурс просто отсутствует.

Шаги для воспроизведения:
1. Выполнить DELETE /booking/{id} с валидным токеном (получить 201).
2. Повторить DELETE /booking/{id} с тем же токеном.
3. Выполнить PUT /booking/{id} для несуществующего id (например, 999999 или "abc").

Фактический результат:
405 Method Not Allowed, тело "Method Not Allowed".

Ожидаемый результат:
404 Not Found — ресурс не найден.

Окружение: ОС Windows 10 Pro, Python 3.14, requests 2.34.2, стенд Heroku (Node/Express).
Автотест: automation/api/test_booking_negative.py::test_operations_on_missing_booking_return_404
