Баг-репорт BUG-01. Некорректное отображение изображений товаров в каталоге

Компонент: Главная страница каталога товаров (/inventory.html)
Серьезность: Высокая (Major)
Приоритет: Высокий (High)

Описание:
При авторизации в системе под учетной записью problem_user на главной странице магазина некорректно отображаются миниатюры товаров. Вместо уникальных изображений соответствующих позиций (рюкзак, куртка, футболка), у всех товаров отображается идентичная графическая заглушка с изображением собаки (мопса с мячом).

Шаги для воспроизведения:
1. Перейти на главную страницу авторизации: https://saucedemo.com
2. В поле ввода Username указать значение: problem_user
3. В поле ввода Password указать значение: secret_sauce
4. Нажать на кнопку Login для входа в систему.
5. Оценить визуальное отображение карточек товаров в каталоге.

Фактический результат:
Все доступные товары отображаются с одинаковым дефолтным изображением-заглушкой. Уникальные фотографии товаров отсутствуют.

Ожидаемый результат:
Каждая карточка товара должна содержать уникальное и соответствующее описанию изображение (например, для товара Saucedemo Backpack должно отображаться фото рюкзака).

Окружение: ОС Windows, браузер Google Chrome.
