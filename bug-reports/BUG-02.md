Баг-репорт BUG-02. Блокировка ввода фамилии при оформлении заказа (Checkout)

Компонент: Форма ввода личных данных (/checkout-step-one.html)
Серьезность: Критическая (Critical)
Приоритет: Высокий (High)

Описание:
При попытке оформить заказ под учетной записью problem_user система блокирует заполнение формы. Поле ввода Last Name (Фамилия) игнорирует любой ввод с клавиатуры. Из-за этого пользователь не может завершить покупку, так как форма выдает ошибку валидации "Error: Last Name is required".

Шаги для воспроизведения:
1. Авторизоваться на сайте под пользователем problem_user.
2. Добавить любой доступный товар в корзину.
3. Перейти в корзину и нажать кнопку Checkout.
4. Ввести любое значение в поле First Name.
5. Попробовать ввести любой текст в поле Last Name.

Фактический результат:
Символы в поле Last Name не отображаются, поле остается пустым. Кнопка Continue выдает ошибку о незаполненном обязательном поле.

Ожидаемый результат:
Поле Last Name должно быть доступно для редактирования и принимать текстовые значения.

Окружение: ОС Windows 10 pro, браузер Google Chrome 150.0.7871.127
