В этой папке будут находиться материалы по тестированию API интернет-магазина.
Здесь будет размещена экспортированная коллекция запросов из программы Postman (файл в формате .json).

-------------------------------------------------------------------------------
Дополнение (фактическое содержимое папки):

Коллекция запросов Postman: ../saucedemo_api_collection.json
Файл экспортирован из Postman, открывается импортом в приложение Postman (File -> Import).
Название: "Sauce Demo - Учебная коллекция QA".

Состав коллекции (3 запроса):
1. Авторизация - Успешный вход (POST https://saucedemo.com)
   Проверка позитивного сценария: ожидается 200 OK и авторизационный токен.
2. Каталог - Получение списка товаров (GET https://saucedemo.com)
   Проверка выдачи списка товаров (заголовок Authorization: Bearer {{token}}).
3. Корзина - Добавление товара (POST https://saucedemo.com)
   Проверка добавления позиции в корзину авторизованного пользователя.

Замечание по стенду: saucedemo.com - это клиентское SPA без публичного HTTP API,
поэтому запросы учебные: они демонстрируют навык проектирования коллекции
(методы, заголовки, тела запросов, описания и ожидаемые результаты).
